Introducción

Las ecuaciones diferenciales son relaciones matemáticas entre una función y sus derivadas. Por ejemplo:

\[ y' = ky \qquad \qquad k \in \mathbb{R} \]

El estudio de estas ecuaciones se motiva por su capacidad para modelizar fenómenos naturales que se expresan naturalmente como ecuaciones diferenciales

Ejemplo 1.1 Un ejemplo conocido es el disparo parabólico, que surge de aplicar las leyes de Newton al movimiento de un proyectil. Un cañón dispara una bala desde la altura \(h_0\) con una velocidad de \(30 m/s\) y un ángulo \(\alpha\). Se puede expresar la posición de bala de cañón a través del siguiente sistema, donde el vector \((x(t), y(t))\) describe la posición de la bala en cada instante de tiempo \(t\):

\[ \begin{cases} y'' = -9.81 \\ x'' = 0 \\ y'(0) = 30 \sin \alpha \\ x'(0) = 30 \cos \alpha\\ y(0) = h_0\\ x(0) = 0 \\ \end{cases} \]

Los tres enfoques distintos a las ecuaciones diferenciales

Las preguntas del ejemplo anterior adelantan los tres enfoques de estudio principales:

  1. Analítico: centrado en calcular una expresión exacta de las soluciones
  2. Cualitativo: centrado en describir el comportamiento de las soluciones sin resolverlas
  3. Numérico: centrado en aproximar soluciones controlando el error

Estos apuntes se centran en métodos de resolución analítica y propiedades de ecuaciones particulares. Cursos posteriores profundizarán en análisis cualitativo (teoría de sistemas dinámicos), métodos numéricos y ecuaciones en derivadas parciales.

Antes de desarrollar la teoría formal, veamos qué tipo de preguntas se pueden responder sobre una ecuación diferencial simple.

Ejemplo informal: crecimiento bacteriano

A continuación se realiza un breve estudio de la ecuación \(y' = a y\). El ejemplo está diseñado para que el alumno intente resolver todos los apartados.

Ejemplo 1.2 La ecuación \(y' = a y\) es una ecuación lineal de primer orden homogenea. Será objeto de estudio a lo largo de la asignatura.

El objetivo de este ejemplo es presentar de manera intuitiva como se pueden estudiar estos problemas.

  1. Sin tener la solución, ¿Cuando la solución es creciente/decreciente?

Solución 1.2. Aunque no se tiene la solución, la ecuación diferencial aporta información sobre su derivada. En particular la función es creciente si y solo si \(y'(x) > 0\).

\[ \boxed{\;y'(x) > 0 \quad \Longleftrightarrow \quad a y(x) > 0 \quad \Longleftrightarrow \quad \operatorname{sgn}(y)= \operatorname{sgn}(a)\;} \]

Esto quiere decir que depende de los valores de a: - Si \(a > 0\), las soluciones positivas son crecientes y las negativas decrecientes. - Si \(a < 0\), las soluciones positivas son decrecientes y las negativas crecientes.

A pesar de que no se conoce la solución, se pueden deducir algunas de sus caracteristicas a partir de la ecuación:

  1. Comprobar que \(y(x) = Ce^{a x}\) con \(C \in \mathbb{R}\) es solución de \(y' = a y\)

Solución 1.2. La función \(y(x) = Ce^{a x}\) es solución de \(y' = a y\). Para demostrarlo se sustituye en la expresión: \[ \boxed{\frac{d}{dx} (Ce^{a x}) = a Ce^{a x} = a y} \]

Sin embargo, surge una pregunta: ¿Existen otras soluciones?

  1. Demostrar que todas las soluciones son de la forma \(y(x) = Ce^{a x}\) con \(C \in \mathbb{R}\). (Pista: multiplicar por \(e^{-ax}\))

Solución 1.3. Si multiplicamos la ecuación por la función \(e^{-a x}\): \[ \boxed{e^{-a x} y' - a e^{-a x} y = 0 \implies \frac{d}{dx}(e^{-a x} y) = 0} \]

Por lo tanto, \(e^{-a x} y\) es constante y todas las soluciones son de la forma \(y(x) = Ce^{a x}\).

La función \(e^{-a x}\) es el factor integrante de la ecuación que proporciona un método de resolución que se estudiará más adelante

La siguiente pregunta es: ¿Qué caracteriza esa constante?

  1. Encontrar el valor de la función que caracteriza la constante.

Solución 1.4. Como en el ejemplo del disparo, se puede tener un punto de la solución como condición de inicio: \(y(0) = y_0\). Entonces la solución es: \[ \boxed{y_0 = y(0) = C e^{a 0} = C \quad \Longrightarrow \quad y(x) = y_0 e^{a x}} \]

Los resultados obtenidos hasta ahora nos ayudan a intuir que las ecuaciones tienen como solución familias de funciones y que las condiciones que se imponen determinan subconjuntos particulares.

La siguiente pregunta es: ¿Cómo varían las soluciones respecto de a?

  1. Describir como varían las soluciones respecto al parámetro a.

Solución 1.5. El comportamiento depende del parámetro \(a\):

  • Si \(a > 0\), las soluciones \(y(x) = y_0 e^{a x}\) son exponenciales crecientes.
  • Si \(a < 0\), las soluciones \(y(x) = y_0 e^{a x}\) son exponenciales decrecientes.
  • Si \(a = 0\), las soluciones \(y(x) = y_0\) son constantes.

Nota: el crecimiento se podía deducir directamente en el primer apartado.

Para estudiar el espacio de soluciones es útil representar todas las soluciones en el plano \((x, y)\). Este espacio se denomina plano de fases.

En el plano se observa que hay una solución constante \(y=0\). Estas soluciones se llaman equilibrios o soluciones estacionarias.

  1. Encontrar todos los equilibrios o soluciones constantes.

Solución 1.7. Soluciones particulares y de interés son las soluciones constates, llamadas puntos de equilibrio. Una solución es constante \(y(x) = k \in \mathbb{R}\) si y solo si \(y'(x) = 0\). Por lo tanto las soluciones de: \[ y' = 0 = a y \quad \Longleftrightarrow \quad a = 0 \lor y = 0 \]

  • Si \(a \neq 0\), el único equilibrio es la función \(0\).
  • Si \(a = 0\), todas las soluciones son equilibrios.

La interpretación geómetrica de la derivada es la pendiente de la recta tangente a la solución. Esto quiere decir que en cada punto la ecuación define la tangente a una o varias soluciones.

Esto nos permite dibujar un campo vectorial asociado en el que en cada punto el vector tiene la pendiente definida por la ecuación.

  1. Definir el campo vectorial asociado a la ecuación diferencial y dibujarlo.

Solución 1.8. El campo de direcciones muestra la pendiente \(y' = a y\) en cada punto \((x, y)\). Este permitirá visualizar el comportamiento local de las soluciones.

Código 
viewof a = Inputs.range([-3, 3], {
  value: -1,
  step: 0.1,
  label: "a"
})
{
  // Dominio
  let x_min = -3, x_max = 3;
  let y_min = -3, y_max = 3;

  // Campo
  let densidad = 20;
  let longitud = 0.35;
  let normalizar = true;

  // Sistema: x' = 1, y' = a*y
  let f = (x, y, t) => 1;
  let g = (x, y, t) => a * y;

  // Color por estabilidad (tiempo hacia delante)
  let colorCampo = (a < 0) ? "green" : (a > 0) ? "red" : "#777";

  // Campo vectorial (2D)
  let calcular_campo_vectorial = (f, g, x_min, x_max, y_min, y_max, densidad, longitud, normalizar) => {
    let vectores = [];
    let dx = (x_max - x_min) / densidad;
    let dy = (y_max - y_min) / densidad;

    for (let x = x_min; x <= x_max; x += dx) {
      for (let y = y_min; y <= y_max; y += dy) {
        let vx = f(x, y, 0);
        let vy = g(x, y, 0);
        if (!isFinite(vx) || !isFinite(vy)) continue;

        let mag = Math.hypot(vx, vy);
        if (mag === 0) continue;

        let scale = normalizar
          ? Math.min(dx, dy) * longitud
          : Math.min(dx, dy) * longitud * Math.min(1, mag);

        let dx_vec = (vx / mag) * scale;
        let dy_vec = (vy / mag) * scale;

        vectores.push({ x1: x, y1: y, x2: x + dx_vec, y2: y + dy_vec });
      }
    }
    return vectores;
  };

  let campo = calcular_campo_vectorial(
    f, g,
    x_min, x_max,
    y_min, y_max,
    densidad,
    longitud,
    normalizar
  );

  return Plot.plot({
    width: 700,
    height: 400,
    marginLeft: 60,
    marginBottom: 60,
    grid: true,
    x: { label: "x →", domain: [x_min, x_max] },
    y: { label: "↑ y", domain: [y_min, y_max] },
    marks: [
      Plot.ruleX([0], { stroke: "black", strokeWidth: 1.5, opacity: 0.25 }),
      Plot.ruleY([0], { stroke: "black", strokeWidth: 1.5, opacity: 0.25 }),

      Plot.arrow(campo, {
        x1: "x1", y1: "y1",
        x2: "x2", y2: "y2",
        stroke: colorCampo,
        strokeWidth: 1.8,
        headLength: 8,
        headAngle: 25,
        opacity: (a === 0) ? 0.35 : 0.75
      })
    ]
  });
}

Para definir el campo es necesario un vector \((\alpha, \beta)\) que tenga como pendiente \(ay\).

Como la pendiente es \(\dfrac{\beta}{\alpha}\), el vector más simple es \((1, ay)\).

Interpretación: Cada flecha indica la dirección y pendiente de la solución en ese punto.

El dibujo se ha hecho numéricamente evaluando en todos los puntos aunque se verán tecnicas para poder aproximarlo sin la necesidad de evaluar tantos puntos.

Además se aprecia que si \(a >0\) las soluciones se alejan del \(0\) mientras que si es negativo se acercan. Esta propriedad de la solución \(0\) se estudiará como estabilidad

  1. Formalizar la intuición anterior usando la expresión de la solución. ¿Cuando convergen las soluciones a 0?

Solución 1.10. Como las soluciones son exponenciales. El límite a infinito converge a \(0\) si el argumento es negativo y convergen a \(\pm \infty\) si es positivo.

Formalmente se dirá que:

  • Para \(a < 0\), el equilibrio \(y = 0\) es estable (las soluciones tienden a cero).
  • Para \(a > 0\), el equilibrio \(y = 0\) es inestable (las soluciones se alejan de cero).

En teoría de sistemas dinámicos estos cambios de comportamiento son muy importantes. Un cambio significativo en el comportamiento de las soluciones puede hacer que un modelo deje de ser representativo o un aviso de que el fenómeno modelado cambiará su comportamiento. Estos eventos se denominan bifurcaciones.

Además el campo de direcciones permite aproximar numéricamente las soluciones. Si aproximamos la solución en un punto por la tangente a ese punto se obtiene el método de Euler.

Para ello, dividimos el espacio en un conjunto de \(N\) puntos equidistantes y de forma iterada aproximamos en cada punto la función por la recta tangente definida por la EDO.

  1. Formalizar la intuición anterior y aproximar \(y' = y\) en \([0,1]\) donde \(y(0)=1\).

Solución 1.10. Para aproximar la solución del problema \(y' = y\), \(y(0) = 1\) en el intervalo \([0,1]\) mediante el método de Euler, dividimos el intervalo en \(N\) pasos de tamaño \(h = 1/N\).

Además para aproximar un punto se usa el punto anterior y la recta tangente a definida por la EDO \(y_{n+1} = y_{n} + h \dot y_n = y_{n-1} + h y_{n-1}\) \[ \begin{cases} \displaystyle x_n = n h = \frac{n}{N} \\ \displaystyle y_0 = 1 \\ \displaystyle y_n = y_{n-1} + h y_{n-1} = (1 + h) y_{n-1} \end{cases} \]

para \(n = 1, 2, \ldots, N\).

Por inducción se obtiene la expresión explícita: \[ y_n = (1 + h)^n = \left(1 + \frac{1}{N}\right)^n \]

      const total = 4 * N;   // 4 fases por paso

  const datos = [];
  let x = x0, y = y0;
  datos.push({ x, y, k: 0 });

  for (let k = 0; k < N; k++) {
    y = y + h * y;
    x = x + h;
    datos.push({ x, y, k: k + 1 });

  // fase 3: se borra segmento, quedan puntos (listo para repetir)
  const m = animar ? frame : 4 * N;

    }

  const visibles = datos.slice(0, ultimoIndiceVisible + 1);

  // segmento del paso k (solo en fase 1 y 2)
  let segmento = [];
  if (animar && k < N && (fase === 1 || fase === 2)) {
    const pk = datos[k];
    const x1s = pk.x + h;
    const y1s = pk.y + h * pk.y;
    segmento = [{ x: pk.x, y: pk.y }, { x: x1s, y: y1s }];

  return Plot.plot({

      // resaltados
      ...(puntoActual.length

Notación y clasificación de ecuaciones

Notación de derivadas

Existen varias notaciones comunes para expresar derivadas en ecuaciones diferenciales:

Notación de Lagrange: \[y', \quad y'', \quad y'''\]

Notación de Newton: \[\dot{y}, \quad \ddot{y}, \quad \dddot{y}\]

Notación de Leibniz: \[\frac{dy}{dt}, \quad \frac{d^2y}{dt^2}, \quad \frac{d^3y}{dt^3}\]

A lo largo del texto se utilizarán principalmente la notación de Lagrange y de Leibniz.

Además a lo largo del libro se usarán distintas letras para la variable independiente (t, x, s, etc.) y la función desconocida (y, u, v, etc.) dependiendo del contexto.

Clasificación de ecuaciones diferenciales

  • Ecuaciones Ordinarias y en Derivadas Parciales
  • Orden
  • Ecuaciones Lineales
  • Ecuaciones Autónomas

Las ecuaciones diferenciales se clasifican según el número de variables independientes:

Ecuaciones Diferenciales Ordinarias (EDO) La función desconocida depende de una única variable independiente. Las derivadas son ordinarias.

\[y' = ky, \quad y'' + \omega^2 y = 0\]

Ecuaciones en Derivadas Parciales (EDP) La función desconocida depende de dos o más variables independientes. Aparecen derivadas parciales.

\[\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}, \quad \nabla^2 u = 0\]

Definición 1.1 (Orden) El orden de una ecuación diferencial es el de la derivada de mayor orden que aparece en ella.

\[ y^{(n)} = f(t, y, y', y'', \ldots, y^{(n-1)}) \]

La ecuación anterior es de orden \(n\).

Ejemplo 1.3  

  • \(y' = 3y^3\) es de orden 1
  • \(y'' + 2y' + y = 0\) es de orden 2
  • \(y''' - y' = \sin(t)\) es de orden 3
  • \(\frac{d^4y}{dt^4} + 2\frac{d^2y}{dt^2} = t^2\) es de orden 4

Definición 1.2 (Ecuación lineal) Una ecuación diferencial ordinaria de orden \(n\) es lineal si puede escribirse en la forma:

\[ a_n(t)y^{(n)} + a_{n-1}(t)y^{(n-1)} + \cdots + a_1(t)y' + a_0(t)y = g(t) \]

donde \(a_i(t)\) y \(g(t)\) son funciones que dependen solo de \(t\) (no de \(y\) ni sus derivadas).

Características clave:

  • La variable dependiente \(y\) y sus derivadas aparecen de forma lineal (no hay productos, potencias, ni composiciones)
  • Si \(g(t) = 0\), la ecuación es homogénea
  • Si \(g(t) \neq 0\), la ecuación es no homogénea

Ejemplo 1.4 Ecuaciones lineales:

  • \(y' + 2y = e^t\) (lineal de orden 1, no homogénea)
  • \(y'' - 3y' + 2y = 0\) (lineal de orden 2, homogénea)
  • \(t^2y'' + ty' - y = \ln t\) (lineal de orden 2, no homogénea)

Ecuaciones no lineales:

  • \(y' = y^2\)
  • \(y'' + (y')^2 + y = 0\)
  • \(y'' + \sin(y) = 0\)

Una ecuación diferencial ordinaria es autónoma si la variable independiente no aparece explícitamente en la ecuación.

Forma general de una EDO autónoma de orden 1: \[y' = f(y)\]

Forma general de una EDO autónoma de orden 2: \[y'' = f(y, y')\]

Ejemplo 1.5 Ecuaciones autónomas:

  • \(y' = ky\)
  • \(y' = y(1 - y)\)
  • \(y'' + \sin(y) = 0\)

Ecuaciones no autónomas:

  • \(y' = t + y\)
  • \(y'' + ty' + y = 0\)
  • \(y' = e^t y\)

Forma estándar y forma normal

Una ecuación diferencial ordinaria de orden \(n\) se puede expresar en forma estándar o forma normal:

Definición 1.3 (Forma estándar) \[ F\left(t, y, y', y'', \ldots, y^{(n)}\right) = 0 \]

La ecuación admite forma normal (o forma explícita) si es posible despejar la derivada de mayor orden:

Definición 1.4 (Forma Normal) \[ y^{(n)} = f\left(t, y, y', y'', \ldots, y^{(n-1)}\right) \]

Ejemplo 1.6 La ecuación \(y'' + 2y' + y = e^t\) en forma normal es: \[ y'' = e^t - 2y' - y \]

En forma estándar es:

\[ y'' - e^t + 2y' + y = 0 \]

Soluciones de ecuaciones

Definición 1.5 (Solución) Una función \(y: I \subset \mathbb{R} \to \mathbb{R}\) (o \(y: I \to \mathbb{R}^m\)) (derivable tantas veces como lo exija la ecuación) se dice solución de una EDO en el intervalo \(I\) si, al sustituir \(y(t)\) y sus derivadas en la ecuación, esta se verifica para todo \(t \in I\).

En particular, si la EDO está en forma normal \[ y^{(n)} = f\left(t, y, y', \ldots, y^{(n-1)}\right), \] entonces \(y\) es solución si cumple \[ y^{(n)}(t) = f\left(t, y(t), y'(t), \ldots, y^{(n-1)}(t)\right)\qquad \forall\, t\in I. \]

Nota: La definición de solución requiere que su dominio sea un intervalo \(I\). Esto tiene dos implicaciones fundamentales: 1. Conexión: No se trabaja en conjuntos no conexos.

  1. Independencia de ramas: Una solución puede generar múltiples soluciones si su dominio no es conexo. Cada intervalo conexo del dominio define una solución diferente.

Más adelante se entenderá el porque de limitar la definición de solución a un intervalo. Esta restricción asegura que la solución sea única y bien definida en ese intervalo.

Soluciones explícitas e implícitas

Las soluciones se pueden expresar de forma explícita o implícita:

Definición 1.6 (Solución Explícita) Una solución es explícita si se puede escribir como una función de la variable independiente \(y = \phi(t)\).

Definición 1.7 (Solución Implícita) Una solución es implícita si se expresa mediante una relación \(G(t, y) = 0\) que define a una o varias funciones \(y=\phi(t)\) diferenciables en algún intervalo.

Ejemplo 1.7 La ecuación \(y' = -\dfrac{x}{y}\) tiene como solución implícita la ecuación \[ y^2 + x^2 = C \quad C \in \mathbb{R} \]

En forma explícita, la solución es \[ y = \pm \sqrt{C - x^2} \quad C \in \mathbb{R} \]

Nota: se observa que la solución implícita no es una función, cada solución implícita puede definir varias soluciones explícitas.

Comprobar que una función es solución

Para comprobar que una función es solución de una EDO, es suficiente con sustituirla en la ecuación y verificar que se cumple.

En los siguientes ejemplos se muestra soluciones de ecuaciones y su comprobación.

  • Una función varias soluciones
  • Implícita
  • Explicita
  • Función a tramos

La ecuación \(y' = \dfrac{1}{x^2}\) tiene como familia de soluciones \(y = -\dfrac{1}{x} + C\) con \(C \in \mathbb{R}\).

Para comprobar que es solución, se sustituye en la ecuación:

\[ \frac{d}{dx} \left( -\frac{1}{x} + C \right) = \frac{1}{x^2} \]

Sin embargo esta función no está definida en \(x=0\). Esto quiere decir que la expresión análitica genera dos soluciones distintas, una definida en \((-\infty, 0)\) y otra definida en \((0, \infty)\). Se denominan soluciones maximales y son objeto de estudio en cursos más avanzados. Además, son solución también en cualquier subintervalo de sus dominios.

Ejemplo 1.8 Dada la ecuación anterior \(y' = -\dfrac{x}{y}\), se comprueba toda función diferenciable \(y\) que sarisfaga la ecuación implícita \(y^2 = -x^2 + C\) es solución.

Derivando ambos lados de la ecuación implícita respecto a \(x\):

\[ y^2 = -x^2 + C \]

\[ \frac{d}{dx}(y^2) = \frac{d}{dx}(-x^2 + C) \]

\[ 2y\frac{dy}{dx} = -2x \]

\[ y' = -\frac{2x}{2y} = -\frac{x}{y} \]

Por lo tanto, la solución implícita es solución de la ecuación.

Ejemplo 1.9 Dada la ecuación anterior \(y' = -\dfrac{x}{y}\), se comprueba que la función explícita \(y = \pm \sqrt{-x^2 + C}\) es solución.

Sustituyendo directamente:

\[ \frac{d}{dx} \left( \pm \sqrt{-x^2 + C} \right) = -\frac{x}{\pm \sqrt{-x^2 + C}} = -\frac{x}{y} \]

Por lo tanto, la solución explícita es solución de la ecuación. Además, es importante definir el intervalo en el que la función es solución, en este caso es solución en cualquier subintervalo de su dominio \(x \in (-\sqrt{C}, \sqrt{C})\). Nótese que la función está definida en el intervalo cerrado \([-\sqrt{C}, \sqrt{C}]\) pero no es solución en los extremos porque no es diferenciable en esos puntos. Este es un buen ejemplo de como la función puede ser solución en un intervalo pero no en su frontera.

De esta reflexión surgirá la necesidad de una teoría que intente extender soluciones a su intervalo maximal de existencia, caracterizar cuando este existe y como se comporta la solución cerca de la frontera.

La ecuación diferencial puede estar definida por partes. Veamos como se comporta:

Ejemplo 1.10 Sea la EDO \[ y' = \begin{cases} \cos x, & x \in (0, \pi), \\ 0, & x \notin (0, \pi). \end{cases} \]

Se puede comprobar que \(\sin x\) es solución en el intervalo \((0, \pi)\) pero no es solución en ningún intervalo que contenga puntos fuera de \((0, \pi)\). Habitualmente, se definen las soluciones a tramos intentando que sean continuas, por ejemplo:

\[ y(x) = \begin{cases} C_1, & x \leq 0, \\ \sin x + C, & x \in (0, \pi), \\ C_2, & x \geq \pi. \end{cases} \]

Esta familia de soluciones define tres soluciones de la ecuación diferencial definidas respectivamente en \((-\infty, 0), (0, \pi), (\pi, \infty)\). Ya que la derivada en \(\{0, \pi\}\) no está definida. Por ejemplo, el límite por la izquierda en \(0\) es \(0\) y por la derecha \(\cos 0 = 1\).

En función del modelo que represente nuestro problema, puede ser interesante definir la solución a tramos de forma que sea continua o incluso diferenciable. En este caso, se puede imponer solo la continuidad y se obtiene \(C_1 = C\) y \(C_2 = C + \sin \pi = C\). Por lo tanto, la familia de soluciones continuas es: \[ y(x) = \begin{cases} C, & x \leq 0, \\ \sin x + C, & x \in (0, \pi), \\ C, & x \geq \pi. \end{cases} \]

Por definición no son solución en los puntos \(\{0, \pi\}\) pero la diferenciabilidad en esos puntos puede no ser necesaria a la hora de estudiar el fénomeno que se está modelizando. En análisis avanzado, este tipo de funciones que cumplen la ecuación en casi todo su dominio se conocen como soluciones en sentido débil o soluciones de Carathéodory.

Problemas de valor inicial y de contorno

Se ha visto que una ecuación diferencial puede no tener una única solución, sino una familia paramétrica de funciones. Por ejemplo \(y = Ce^{ax}\) para \(y' = ay\). Sin embargo, un modelo describe un fenómeno concreto, así que una continuación natural es determinar cuál de todas esas soluciones es la que corresponde al fenómeno.

Para ello se imponen condiciones adicionales que seleccionen un subconjunto de la familia. Por ejemplo que pase por un punto, que tenga una pendiente dada o que tome valores prescritos en los extremos de un intervalo. La ecuación junto con estas condiciones forma un nuevo problema para el que se estudiará la existencia y unicidad de soluciones.

Según la forma de las condiciones se pueden caracterizar los problemas en diferentes tipos. En el curso se estudiarán principalmente los problemas de valor inicial y los problemas de contorno.

Problemas de valor inicial

Definición 1.8 (Problema de valor inicial (PVI) o problema de Cauchy) Sean \(I \subset \mathbb{R}\) un intervalo, \(t_0 \in I\), \(f\) una función dada y \(y_0, \ldots, y_{n-1} \in \mathbb{R}\). Un problema de valor inicial de orden \(n\) es el sistema \[ \begin{cases} y^{(n)}(t) = f\left(t, y(t), y'(t), \ldots, y^{(n-1)}(t)\right), & t \in I, \\[2pt] y(t_0) = y_0,\ y'(t_0) = y_1,\ \ldots,\ y^{(n-1)}(t_0) = y_{n-1}. \end{cases} \]

Un PVI puede tener una única solución, ninguna o varias:

  • Unicidad
  • No existencia
  • Número finito
  • Infinitas soluciones

Existe una única solución.

Ejemplo 1.11 (PVI con solución única) Se considera el PVI \[ \begin{cases} y'' + y = 0, \\ y(0) = 0, \\ y'(0) = 1. \end{cases} \]

Solución. Las soluciones de la ecuación, como se comprueba sustituyendo, son \(y(x) = A\cos x + B\sin x\) con \(A, B \in \mathbb{R}\). Las condiciones iniciales dan \(y(0) = A = 0\) e \(y'(0) = B = 1\), luego \(y(x) = \sin x\). Hay una única solución, y además definida para todo \(x \in \mathbb{R}\).

No existe ninguna solución.

Ejemplo 1.12 (Problema sin solución) Se considera \[ \begin{cases} x y' = 1, \\ y(0) = 0. \end{cases} \]

Solución. Si \(y\) fuera solución en un intervalo que contiene a \(0\), al evaluar la ecuación en \(x = 0\) se obtendría \(0 \cdot y'(0) = 1\), es decir, \(0 = 1\). Por tanto, no hay solución.

Fuera de \(x = 0\) la ecuación equivale a \(y' = 1/x\), cuyas soluciones \(y = \ln|x| + C\) no están acotadas cerca de \(0\).

Técnicamente, no es un PVI en el sentido de Definición 1.8, porque la ecuación no admite forma normal en \(x = 0\): no se puede despejar \(y'\) como \(f(x,y)\) con \(f\) definida en ese punto.

Existe un número finito de soluciones, mayor que uno.

Ejemplo 1.13 (Problema con exactamente dos soluciones) Se considera \[ \begin{cases} (y')^2 = 1, \\ y(0) = 0. \end{cases} \]

Solución. Las funciones \(y(x) = x\) e \(y(x) = -x\) son soluciones. Además, no hay ninguna más: si \(y\) es solución, \(y'\) solo toma los valores \(1\) y \(-1\), y como una derivada tiene la propiedad del valor intermedio (teorema de Darboux), \(y'\) es constante. Por tanto, hay exactamente dos soluciones. Tampoco se pueden empalmar tramos de ambas, porque la función resultante no sería derivable en el punto de empalme.

Técnicamente, no es un PVI en el sentido de Definición 1.8, porque la ecuación no admite forma normal: al despejar se obtiene \(y' = \pm 1\), que no es una única función \(f(x,y)\). Un resultado interesante es que para una EDO en forma normal con \(f\) continua, si hay más de una solución, hay infinitas.

Existen infinitas soluciones.

Ejemplo 1.14 (PVI con infinitas soluciones) Se considera \[ \begin{cases} y' = \sqrt{y}, \\ y(0) = 0. \end{cases} \]

Solución. La función \(y = 0\) es solución. Si \(y > 0\), separando variables, \(\dfrac{\mathrm{d}y}{\sqrt{y}} = \mathrm{d}x\) da \(2\sqrt{y} = x - c\), es decir, \(y = \dfrac{(x-c)^2}{4}\) para \(x > c\). Pegando ambas piezas, para cada \(c \geq 0\) la función \[ y_c(x) = \begin{cases} 0, & x \leq c, \\[2pt] \dfrac{(x-c)^2}{4}, & x > c, \end{cases} \] es derivable en todo \(\mathbb{R}\) (en \(x = c\) ambas derivadas valen \(0\)) y es solución del PVI. La solución puede despegar del equilibrio \(y = 0\) en cualquier instante \(c \geq 0\), de modo que hay infinitas soluciones.

Problemas de contorno

Definición 1.9 (Problema de valores en la frontera) Sean \(a < b\), \(f\) una función dada y \(g_1, \ldots, g_n\) funciones dadas. Un problema de valores en la frontera (o de contorno) de orden \(n \geq 2\) es el sistema \[ \begin{cases} y^{(n)}(x) = f\left(x, y(x), y'(x), \ldots, y^{(n-1)}(x)\right), & x \in (a,b), \\[2pt] g_i\left(y(a), \ldots, y^{(n-1)}(a),\, y(b), \ldots, y^{(n-1)}(b)\right) = 0, & i = 1, \ldots, n. \end{cases} \]

Tipos de condiciones de contorno

Se vuelve a considerar la ecuación \(y'' + y = 0\), de solución general \(y(x) = A\cos x + B\sin x\). La ecuación es siempre la misma, sin embargo, según las condiciones, se obtiene una, infinitas o ninguna solución.

  • Dirichlet
  • Neumann
  • Robin
  • Otras

Se fija el valor de la solución en los extremos: \(y(a) = \alpha\), \(y(b) = \beta\).

Ejemplo 1.15 (Condiciones de Dirichlet) Sobre \([0, \pi]\), se estudian las soluciones, según el valor de \(\beta\), de \[ \begin{cases} y'' + y = 0, & x \in (0,\pi), \\ y(0) = 0, \\ y(\pi) = \beta. \end{cases} \]

Solución. Con \(y = A\cos x + B\sin x\), la primera condición da \(A = 0\) y la segunda \(y(\pi) = -A = \beta\):

  • Si \(\beta = 0\): \(B\) queda libre, luego \(y(x) = B\sin x\). Infinitas soluciones.
  • Si \(\beta \neq 0\) (por ejemplo \(\beta = 1\)): se exige \(-A = \beta\) pero \(A = 0\). No hay solución.

Sin embargo, el problema \[ \begin{cases} y'' + y = 0, & x \in (0,\pi/2), \\ y(0) = 0, \\ y(\pi/2) = 1, \end{cases} \] da \(A = 0\), \(B = 1\) y la solución única \(y(x) = \sin x\).

Se fija el valor de la derivada en los extremos: \(y'(a) = \alpha\), \(y'(b) = \beta\). Físicamente suele representar un flujo (de calor, de materia…) en el borde.

Ejemplo 1.16 (Condiciones de Neumann) Sobre \([0, \pi]\), se considera \[ \begin{cases} y'' + y = 0, & x \in (0,\pi), \\ y'(0) = 0, \\ y'(\pi) = 0. \end{cases} \]

Solución. Como \(y'(x) = -A\sin x + B\cos x\), la primera condición da \(B = 0\) y la segunda se cumple siempre. Quedan infinitas soluciones \(y(x) = A\cos x\).

Se fija una combinación del valor y de la derivada: \(y'(a) + \gamma\, y(a) = \alpha\), con \(\gamma \in \mathbb{R}\). Contiene a Dirichlet y a Neumann como casos particulares, y también se pueden imponer condiciones de tipos distintos en cada extremo.

Ejemplo 1.17 (Condición de Robin) Sobre \([0, \pi]\), se considera \[ \begin{cases} y'' + y = 0, & x \in (0,\pi), \\ y(0) = 0, \\ y'(\pi) + y(\pi) = 1. \end{cases} \]

Solución. De \(y(0)=0\) se tiene \(y = B\sin x\), y entonces \(y'(\pi) + y(\pi) = -B = 1\). La solución única es \(y(x) = -\sin x\).

Existen muchas más posibilidades. Por ejemplo, las condiciones periódicas \(y(a) = y(b)\), \(y'(a) = y'(b)\) también encajan en la definición de problema de frontera. Las condiciones en puntos interiores del intervalo no encajan en ella y no se estudian.

Los ejemplos anteriores ilustran distintos tipos de condiciones en los problemas de frontera y cómo restricciones diferentes sobre la solución afectan a la existencia y unicidad de soluciones.

Las pregunta relacionadas con las caracteristicas de las soluciones, como su existencia, unicidad, estabilidad y comportamiento a largo plazo, son el objeto de estudio del análisis cualitativo de las ecuaciones diferenciales. En la siguiente sección se tratarán ejemplos y técnicas para abordar estos aspectos.

Análisis cualitativo

Cualquier caracteristica de las soluciones de una ecuación diferencial deducida sin conocer la solución explícita es objeto de estudio del análisis cualitativo. Es un campo amplio y con distintos enfoques, por ejemplo la existencia y unicidad de soluciones, comportamiento asintótico y la existencia de soluciones periódicas o casi periódicas.

Existencia y Unicidad de soluciones

El desarrollo de la teoría completa requiere herramientas de análisis que no se abordarán, pero se presentarán los resultados esenciales y sus implicaciones.

Existencia: teorema de Peano

El teorema de Peano establece que la continuidad de \(f\) es condición suficiente para la existencia local de solución.

Teorema 1.1 (Teorema de existencia de Peano) Sean \(\Omega \subset \mathbb{R} \times \mathbb{R}^n\) abierto y \(f \colon \Omega \to \mathbb{R}^n\) continua. Entonces, para cada \((t_0, y_0) \in \Omega\) existe \(\delta > 0\) tal que el PVI \[ \begin{cases} y' = f(t,y), \\ y(t_0) = y_0, \end{cases} \] tiene al menos una solución definida en \([t_0 - \delta, t_0 + \delta]\).

Observación. El PVI de Ejemplo 1.14 tiene \(f\) continua, así que el teorema de Peano asegura su existencia, pero no su unicidad: la continuidad no basta para ella. En cambio, el PVI de Ejemplo 1.12 no contradice el teorema: su ecuación no admite forma normal en \(x = 0\) y, al despejar, \(f(x,y) = 1/x\) no es continua allí.

Unicidad: teorema de Picard-Lindelöf

Para garantizar la unicidad de la solución, se requiere una condición adicional sobre la función \(f\). A continuación se introducen conocimientos sobre este resultado con el objetivo de desarrollar una intuición y de picar la curiosidad del lector sobre una continuidad natural de esta asignatura.

Funciones lipschitzianas

La condición para unicidad será la lipschitzianid de \(f\). Aunque la equivalencia más comoda en terminos practicos es la regularidad respecto de la variable dependiente \(y\), que limita la rapidez con la que \(f(t,y)\) puede variar al cambiar \(y\).

En lo que sigue, \(\|\cdot\|\) denota una norma fija de \(\mathbb{R}^n\).

Definición 1.10 (Función globalmente lipschitziana) Sean \(I \subset \mathbb{R}\) un intervalo, \(E \subset \mathbb{R}^n\) y \(f \colon I \times E \to \mathbb{R}^n\). Se dice que \(f\) es globalmente lipschitziana en \(y\) (uniformemente en \(t\)) en \(I \times E\) si existe \(L \geq 0\) tal que \[ \|f(t,y_1) - f(t,y_2)\| \leq L\,\|y_1 - y_2\| \qquad \text{para todo } t \in I,\ y_1, y_2 \in E. \] \(L\) es la constante de Lipschitz de la función.

También se puede definir la Lipschitzianidad de manera local, considerando entornos alrededor de cada punto.

Definición 1.11 (Función localmente lipschitziana) Sean \(\Omega \subset \mathbb{R} \times \mathbb{R}^n\) abierto y \(f \colon \Omega \to \mathbb{R}^n\). Se dice que \(f\) es localmente lipschitziana en \(y\) si cada punto \((t_0, y_0) \in \Omega\) tiene un entorno \([t_0-a, t_0+a] \times \overline{B}(y_0, r) \subset \Omega\) en el que \(f\) es globalmente lipschitziana en \(y\) (Definición 1.10). La constante \(L\) puede depender del entorno.

La definición de Lipschitz puede ser difícil de verificar directamente. Cuando \(f\) es derivable respecto de \(y\), la condición de Lipschitz equivale a que esa derivada esté acotada.

Proposición 1.1 (Condición de Lipschitz y derivadas acotadas) Sean \(I \subset \mathbb{R}\) un intervalo, \(E \subset \mathbb{R}^n\) abierto y convexo, y \(f \colon I \times E \to \mathbb{R}^n\) continua con derivada parcial \(\dfrac{\partial f}{\partial y}\) (matriz jacobiana respecto de \(y\)) continua en \(I \times E\). Dado \(L \geq 0\), son equivalentes:

  1. \(f\) es globalmente lipschitziana en \(y\) con constante \(L\).
  2. \(\left\| \dfrac{\partial f}{\partial y}(t,y) \right\| \leq L\) para todo \((t,y) \in I \times E\).

El criterio más aplicable en la practica para verificar la Lipschitzianidad se limita a comprobar si la derivada parcial respecto de \(y\) está acotada para garantizar lipschitzianidad local.

Corolario 1.1 (Criterio de lipschitzianidad local) Sea \(\Omega \subset \mathbb{R} \times \mathbb{R}^n\) abierto y \(f \colon \Omega \to \mathbb{R}^n\) continua con \(\dfrac{\partial f}{\partial y}\) continua en \(\Omega\). Entonces \(f\) es localmente lipschitziana en \(y\).

Ejemplo 1.18 (Funciones lipschitzianas y no lipschitzianas) Se estudia si las siguientes funciones son lipschitzianas en \(y\):

  1. \(f(t,y) = \sin y\) en \(\mathbb{R} \times \mathbb{R}\);

  2. \(f(t,y) = y^2\) en \(\mathbb{R} \times \mathbb{R}\);

  3. \(f(t,y) = \sqrt{|y|}\) en \(\mathbb{R} \times \mathbb{R}\).

Solución.

  1. \(\left|\dfrac{\partial f}{\partial y}\right| = |\cos y| \leq 1\) en \(\mathbb{R}\). Por la Proposición 1.1, \(f\) es globalmente lipschitziana con \(L = 1\).

  2. \(\dfrac{\partial f}{\partial y} = 2y\) no está acotada en \(\mathbb{R}\). De hecho, \(|f(t,y_1) - f(t,y_2)| = |y_1+y_2|\,|y_1-y_2|\) y el factor \(|y_1+y_2|\) no está acotado, luego \(f\) no es globalmente lipschitziana. En cada intervalo \([-R,R]\) la derivada está acotada por \(2R\), así que sí es localmente lipschitziana (Corolario 1.1).

  3. \(\dfrac{|f(t,y) - f(t,0)|}{|y|} = |y|^{-1/2} \to \infty\) cuando \(y \to 0\), luego \(f\) no es lipschitziana en ningún entorno de \(y = 0\). Equivalentemente, \(\dfrac{\partial f}{\partial y} = \dfrac{\operatorname{sgn} y}{2\sqrt{|y|}}\) no está acotada cerca de \(0\). Esto es lo que ocurre en Ejemplo 1.14, donde falla la unicidad.

Teorema de Picard–Lindelöf

Si se exige a \(f\) continuidad y la condición de Lipschitz respecto de \(y\), se obtiene unicidad. Hay dos versiones, según se imponga la condición en todo el espacio o solo localmente.

Teorema 1.2 (Teorema de Picard–Lindelöf (versión global)) Sean \(I = [a,b]\) y \(f \colon I \times \mathbb{R}^n \to \mathbb{R}^n\) continua y globalmente lipschitziana en \(y\), uniformemente en \(t\). Entonces, para cualesquiera \(t_0 \in I\) e \(y_0 \in \mathbb{R}^n\), el PVI \[ \begin{cases} y' = f(t,y), \\ y(t_0) = y_0, \end{cases} \] tiene una única solución definida en todo el intervalo \(I\).

La versión local solo garantiza existencia y unicidad en un entorno del punto inicial.

Teorema 1.3 (Teorema de Picard–Lindelöf (versión local)) Sean \(\Omega \subset \mathbb{R} \times \mathbb{R}^n\) abierto y \(f \colon \Omega \to \mathbb{R}^n\) continua y localmente lipschitziana en \(y\). Entonces, para cada \((t_0, y_0) \in \Omega\) existe \(\delta > 0\) tal que el PVI \[ \begin{cases} y' = f(t,y), \\ y(t_0) = y_0, \end{cases} \] tiene una única solución definida en \([t_0 - \delta, t_0 + \delta]\).

La demostración se basa en que \(y\) es solución del PVI si y solo si es continua y cumple la ecuación integral \[ y(t) = y_0 + \int_{t_0}^{t} f(s, y(s))\,\mathrm{d}s. \] Si \(f\) es lipschitziana en \(y\), la aplicación que a una función \(y\) le asigna el segundo miembro es una contracción y el teorema del punto fijo de Banach da existencia y unicidad.

Observación. La condición de Lipschitz es suficiente pero no necesaria para la unicidad. Además, en la versión local \(\delta\) depende del punto \((t_0, y_0)\), y no se puede sustituir por un intervalo fijo, como muestra el siguiente ejemplo.

Ejemplo 1.19 (Existencia solo local) Se considera \[ \begin{cases} y' = y^2, \\ y(0) = 1. \end{cases} \]

Solución. La función \(f(t,y) = y^2\) es de clase \(C^1\), luego localmente lipschitziana (Corolario 1.1). Por el Teorema 1.3 hay una única solución local. Separando variables se obtiene \[ y(t) = \frac{1}{1-t}, \qquad t < 1, \] que explota en tiempo finito: \(y \to \infty\) cuando \(t \to 1^-\). La solución solo existe en \((-\infty, 1)\) aunque \(f\) sea regular en todo \(\mathbb{R}\), y no es globalmente lipschitziana (Ejemplo 1.18), así que no se puede aplicar la versión global.

En resumen, para \(y' = f(t,y)\) con \(y(t_0) = y_0\):

Hipótesis sobre \(f\) Conclusión
Continua Existencia local (Peano)
Continua y localmente lipschitziana en \(y\) Existencia y unicidad locales (Picard–Lindelöf local)
Continua y globalmente lipschitziana en \(y\) Existencia y unicidad en todo \(I\) (Picard–Lindelöf global)

Comportamiento de las soluciones

Una práctica frecuente, consiste en deducir propiedades de las soluciones a partir de las profiedades de la ecuación diferencial.

Se procederá a definir un campo vectorial asociado a la ecuación diferencial, un conjunto de curvas (isoclinas) que lo describen y técnicas para deducir el comportamiento de las soluciones como monotonía, límite y estabilidad.

Campo de direcciones e isoclinas

Dada una ecuación diferencial de la forma \(y' = f(x,y)\), se puede asociar un campo de direcciones que describe la pendiente de las soluciones en cada punto del plano \((x,y)\). Este campo permite visualizar cómo se comportan las soluciones ya que localmente las soluciones son tangentes al campo en cada punto.

Definición 1.12 (Campo de direcciones) Sean \(\Omega \subset \mathbb{R}^2\) y \(f \colon \Omega \to \mathbb{R}\). El campo de direcciones de la ecuación \(y' = f(x,y)\) es el campo vectorial \[ \Omega \to \mathbb{R}^2, \qquad (x,y) \longmapsto \big(1,\ f(x,y)\big), \] que asigna a cada punto \((x,y)\) la dirección de pendiente \(f(x,y)\).

Observación. La pendiente de un vector \((v_1, v_2)\) es \(v_2 / v_1\). Para que el campo tenga pendiente \(f(x,y)\) en el punto \((x,y)\) basta con elegir un vector con \(v_2 / v_1 = f(x,y)\). La opción más sencilla es \(v_1 = 1\), que da el vector \(\big(1,\ f(x,y)\big)\). Normalmente se normaliza el campo para que tenga longitud unitaria. \[ \frac{(1, f(x,y))}{\sqrt{1 + f(x,y)^2}} \]

Dibujar el campo de direcciones consiste en representar en cada punto de una malla un vector que indique la dirección de la pendiente. Para facilitar el trabajo se encuentran las curvas donde la pendiente es constante. De esta manera se pueden dibujar el campo de manera más rápida.

Definición 1.13 (Isoclina) Sea \(m \in \mathbb{R}\). La isoclina de pendiente \(m\) de la ecuación \(y' = f(x,y)\) es el conjunto de soluciones de la ecuación \[ \{(x,y) \in \Omega : f(x,y) = m\}. \]

Ejemplo 1.21 (Campo de y’ = x/y) Se considera la ecuación \[ y' = \frac{x}{y}, \qquad y \neq 0. \]

  • Definir el campo de direcciones
  • Definir las isoclinas

Solución. Campo de direcciones. Por Definición 1.12, el campo es \(\left(1, \dfrac{x}{y}\right)\).

Isoclinas. La ecuación \(\dfrac{x}{y} = m\) equivale a \[ y = \frac{x}{m} \quad \text{si } m \neq 0, \qquad x = 0 \quad \text{si } m = 0. \] Son rectas vectoriales (por el origen, que se excluye) de pendiente \(1/m\), la inversa de la del campo en sus puntos. Para \(m = \pm 1\) ambas pendientes coinciden, así que las rectas \(y = \pm x\) son isoclinas y a la vez soluciones. Para \(m = 0\) la isoclina es el eje \(y\) y el campo es horizontal.

Comportamiento de las soluciones. Las rectas \(y = x\) e \(y = -x\) son las únicas isoclinas tangentes al campo (\(m = \pm 1\)), luego también son soluciones, y ninguna otra solución las puede cruzar. En el cuadrante \(x>0,\,y>0\) el signo de \(y' = x/y > 0\) hace que las soluciones sean crecientes; al no poder cruzar la recta \(y = x\) y ser monótonas, se aproximan a ella asintóticamente cuando \(x \to \infty\), por encima o por debajo según el punto de partida. Por simetría (\(f(-x,-y) = f(x,y)\) y \(f(x,-y) = -f(x,y)\)), el mismo argumento da en los demás cuadrantes ramas asintóticas a \(y = x\) o a \(y = -x\): las soluciones son ramas de hipérbola con esas dos rectas como asíntotas.

Ejemplo 1.23 (Campo de y’ = -y/x) Se considera la ecuación \[ y' = -\frac{y}{x}, \qquad x \neq 0. \]

  • Definir el campo de direcciones
  • Definir las isoclinas
  • Dibujar el campo y analizar el comportamiento de las soluciones

Solución. Campo de direcciones. Por Definición 1.12, el campo es \(\left(1, -\dfrac{y}{x}\right)\).

Isoclinas. La ecuación \(-\dfrac{y}{x} = m\) equivale a \[ y = -mx, \qquad m \in \mathbb{R}. \] Son rectas vectoriales (por el origen, que se excluye) de pendiente \(-m\), la opuesta a la del campo en sus puntos. Solo para \(m = 0\) coinciden: el eje \(x\) es isoclina y solución.

Comportamiento de las soluciones. El eje \(x\) (\(m = 0\)) es la única isoclina tangente al campo, y la única que es también solución. El signo de \(y' = -y/x\) hace que las soluciones decrezcan en los cuadrantes I y III y crezcan en el II y IV. Modelos

Los modelos matemáticos que estudiaremos cumplen tres propiedades fundamentales:

  • Determinismo: el estado futuro y pasado del sistema está completamente determinado por su estado inicial. No existe ambigüedad: las soluciones determinadas por las condiciones iniciales son únicas.
  • Diferenciabilidad: las funciones que describen la evolución del sistema son continuas y derivables. Esta hipótesis, nos permitirá garantizar la existencia de soluciones.
  • Finito-dimensionalidad: el sistema se describe mediante un número finito de variables. Cada estado del sistema puede representarse como un punto en un espacio euclídeo de dimensión \(n\).

En conjunto, estas tres propiedades definen el marco clásico de las ecuaciones diferenciales ordinarias, que constituyen la base teórica de buena parte de la modelización matemática en ciencias e ingeniería.

## Introducción

Las ecuaciones diferenciales son relaciones matemáticas entre una función y sus derivadas. Por ejemplo:

$$
y' = ky \qquad \qquad k \in \mathbb{R}
$$

El estudio de estas ecuaciones se motiva por su capacidad para modelizar fenómenos naturales que se expresan naturalmente como ecuaciones diferenciales

::: {#exm-disparocanon .make-collapse data-title="Ejemplo: Disparo Parabolico"}

Un ejemplo conocido es el disparo parabólico, que surge de aplicar las leyes de Newton al movimiento de un proyectil. Un cañón dispara una bala desde la altura $h_0$ con una velocidad de $30 m/s$ y un ángulo $\alpha$. 
Se puede expresar la posición de  bala de cañón a través del siguiente sistema, donde el vector $(x(t), y(t))$ describe la posición de la bala en cada instante de tiempo $t$:

$$
\begin{cases}
  y'' = -9.81 \\
  x'' = 0 \\
  y'(0) = 30 \sin \alpha \\
  x'(0) = 30 \cos \alpha\\
  y(0) = h_0\\
  x(0) = 0 \\
\end{cases}
$$

::: {.content-visible when-format="html"}

### Los tres enfoques distintos a las ecuaciones diferenciales

Las preguntas del ejemplo anterior adelantan los tres enfoques de estudio principales:

1. **Analítico:** centrado en calcular una expresión exacta de las soluciones
2. **Cualitativo:** centrado en describir el comportamiento de las soluciones sin resolverlas
3. **Numérico:** centrado en aproximar soluciones controlando el error

Estos apuntes se centran en **métodos de resolución analítica** y propiedades de **ecuaciones particulares**. Cursos posteriores profundizarán en análisis cualitativo (teoría de sistemas dinámicos), métodos numéricos y ecuaciones en derivadas parciales.

### Ejemplo informal: crecimiento bacteriano

A continuación se realiza un breve estudio de la ecuación $y' = a y$. El ejemplo está diseñado para que el **alumno intente** resolver todos los apartados.


:::{#exm-exponential .exercise data-title="Ecuación lineal" .make-collapse}

La ecuación $y' = a y$ es una ecuación lineal de primer orden homogenea. Será objeto de estudio a lo largo de la asignatura.

El objetivo de este ejemplo es presentar de manera intuitiva como se pueden estudiar estos problemas.



1. Sin tener la solución, ¿**Cuando la solución es creciente/decreciente**?

::: {#sol-01-comprobar .make-collapse data-title="Monotonía de las soluciones"}
Aunque no se tiene la solución, la ecuación diferencial aporta información sobre su derivada. 
En particular la función es creciente si y solo si $y'(x) > 0$.

$$
\boxed{\;y'(x) > 0 \quad \Longleftrightarrow \quad a y(x) > 0 \quad \Longleftrightarrow \quad \operatorname{sgn}(y)= \operatorname{sgn}(a)\;}
$$

Esto quiere decir que depende de los valores de a:
- Si $a > 0$, las soluciones positivas son crecientes y las negativas decrecientes.
- Si $a < 0$, las soluciones positivas son decrecientes y las negativas crecientes.

:::

A pesar de que no se conoce la solución, se pueden deducir algunas de sus caracteristicas a partir de la ecuación:

2. Comprobar que $y(x) = Ce^{a x}$ con $C \in \mathbb{R}$ **es solución** de $y' = a y$


::: {#sol-01-comprobar .make-collapse data-title="Comprobar si una función es solución"}
La función $y(x) = Ce^{a x}$ es solución de $y' = a y$. Para demostrarlo se sustituye en la expresión:
$$
\boxed{\frac{d}{dx} (Ce^{a x}) = a Ce^{a x} = a y}
$$

Sin embargo, surge una pregunta: ¿Existen otras soluciones?
:::

3. Demostrar que todas las soluciones son de la **forma** $y(x) = Ce^{a x}$ con $C \in \mathbb{R}$. (Pista: multiplicar por $e^{-ax}$)

::: {#sol-01-unicidad .make-collapse data-title="Demostrar que la solución anterior es única salvo constante"}
Si multiplicamos la ecuación por la función $e^{-a x}$:
$$
\boxed{e^{-a x} y' - a e^{-a x} y = 0 \implies \frac{d}{dx}(e^{-a x} y) = 0}
$$

Por lo tanto, $e^{-a x} y$ es constante y todas las soluciones son de la forma $y(x) = Ce^{a x}$.

La función $e^{-a x}$ es el **factor integrante** de la ecuación que proporciona un método de resolución que se estudiará más adelante

La siguiente pregunta es: ¿Qué caracteriza esa constante?
:::

4. Encontrar el valor de la función que caracteriza la constante.

::: {#sol-01-pvi .make-collapse data-title="Problemas de valor inicial (PVI)"}
Como en el ejemplo del disparo, se puede tener un punto de la solución como condición de inicio: $y(0) = y_0$. Entonces la solución es:
$$
\boxed{y_0 = y(0) = C e^{a 0} = C \quad \Longrightarrow \quad y(x) = y_0 e^{a x}}
$$

Los resultados obtenidos hasta ahora nos ayudan a intuir que las ecuaciones tienen como solución familias de funciones y que las condiciones que se imponen determinan subconjuntos particulares.

La siguiente pregunta es: ¿Cómo varían las soluciones respecto de a?
:::

5. Describir como varían las soluciones respecto al **parámetro a**.

::: {#sol-01-parametro .make-collapse data-title="Estudio paramétrico"}
El comportamiento depende del parámetro $a$:

- Si $a > 0$, las soluciones $y(x) = y_0 e^{a x}$ son exponenciales **crecientes**.
- Si $a < 0$, las soluciones $y(x) = y_0 e^{a x}$ son exponenciales **decrecientes**.
- Si $a = 0$, las soluciones $y(x) = y_0$ son **constantes**.

**Nota:** el crecimiento se podía deducir directamente en el primer apartado.
:::

7. Encontrar todos los **equilibrios** o soluciones constantes.

::: {#sol-01-equilibrio .make-collapse data-title="Solución: Equilibrio"}
Soluciones particulares y de interés son las soluciones constates, llamadas puntos de equilibrio. Una solución es constante $y(x) = k \in \mathbb{R}$ si y solo si $y'(x) = 0$. 
Por lo tanto las soluciones de:
$$
y' = 0 = a y \quad \Longleftrightarrow \quad a = 0 \lor y = 0
$$

- Si $a \neq 0$, el único equilibrio es la función $0$. 
- Si $a = 0$, todas las soluciones son equilibrios.
:::

La **interpretación geómetrica** de la derivada es la pendiente de la recta tangente a la solución. Esto quiere decir que en cada punto la ecuación define la tangente a una o varias soluciones.

Esto nos permite dibujar un campo vectorial asociado en el que en cada punto el vector tiene la pendiente definida por la ecuación.

8. Definir el **campo vectorial** asociado a la ecuación diferencial y dibujarlo.

::: {#sol-01-campo .make-collapse data-title="Campo de direcciones paramétrico"}

  label: "a"

{
  // Dominio
  let x_min = -3, x_max = 3;
  let y_min = -3, y_max = 3;

  // Campo
  let densidad = 20;
  let longitud = 0.35;
  let normalizar = true;

  // Sistema: x' = 1, y' = a*y
  let f = (x, y, t) => 1;
  let g = (x, y, t) => a * y;

  // Color por estabilidad (tiempo hacia delante)
  let colorCampo = (a < 0) ? "green" : (a > 0) ? "red" : "#777";

  // Campo vectorial (2D)
  let calcular_campo_vectorial = (f, g, x_min, x_max, y_min, y_max, densidad, longitud, normalizar) => {
    let vectores = [];
    let dx = (x_max - x_min) / densidad;
    let dy = (y_max - y_min) / densidad;

    for (let x = x_min; x <= x_max; x += dx) {
      for (let y = y_min; y <= y_max; y += dy) {
        let vx = f(x, y, 0);
        let vy = g(x, y, 0);
        if (!isFinite(vx) || !isFinite(vy)) continue;

        let mag = Math.hypot(vx, vy);
        if (mag === 0) continue;

        let scale = normalizar
          ? Math.min(dx, dy) * longitud
          : Math.min(dx, dy) * longitud * Math.min(1, mag);

        let dx_vec = (vx / mag) * scale;
        let dy_vec = (vy / mag) * scale;

        vectores.push({ x1: x, y1: y, x2: x + dx_vec, y2: y + dy_vec });
      }
    }
    return vectores;
  };

  let campo = calcular_campo_vectorial(
    f, g,
    x_min, x_max,
    y_min, y_max,
    densidad,
    longitud,
    normalizar
  );

  return Plot.plot({

        strokeWidth: 1.8,
        headLength: 8,
        headAngle: 25,
        opacity: (a === 0) ? 0.35 : 0.75
      })
    ]
  });

8. Formalizar la intuición anterior usando la expresión de la solución. ¿Cuando **convergen las soluciones a 0**?

::: {#sol-01-estable .make-collapse data-title="Solución: Equilibrio y estabilidad"}

Como las soluciones son exponenciales. El límite a infinito converge a $0$ si el argumento es negativo y convergen a $\pm \infty$ si es positivo.

Formalmente se dirá que:

- Para $a < 0$, el equilibrio $y = 0$ es **estable** (las soluciones tienden a cero).
- Para $a > 0$, el equilibrio $y = 0$ es **inestable** (las soluciones se alejan de cero).
:::


En teoría de sistemas dinámicos estos cambios de comportamiento son muy importantes. 
Un cambio significativo en el comportamiento de las soluciones puede hacer que un modelo deje de ser representativo o un aviso de que el fenómeno modelado cambiará su comportamiento.
Estos eventos se denominan **bifurcaciones**.

Además el campo de direcciones permite aproximar numéricamente las soluciones. Si aproximamos la solución en un punto por la tangente a ese punto se obtiene el **método de Euler**.

Para ello, dividimos el espacio en un conjunto de $N$ puntos equidistantes y de forma iterada aproximamos en cada punto la función por la recta tangente definida por la EDO.


9. Formalizar la intuición anterior y aproximar $y' = y$ en $[0,1]$ donde $y(0)=1$.

::: {#sol-01-estable .make-collapse data-title="Solución: Método de Euler"}

Para aproximar la solución del problema $y' = y$, $y(0) = 1$ en el intervalo $[0,1]$ mediante el método de Euler, dividimos el intervalo en $N$ pasos de tamaño $h = 1/N$.

Además para aproximar un punto se usa el punto anterior y la recta tangente a definida por la EDO $y_{n+1} = y_{n} + h \dot y_n = y_{n-1} + h y_{n-1}$
$$
\begin{cases}
\displaystyle x_n = n h = \frac{n}{N} \\
\displaystyle y_0 = 1 \\
\displaystyle y_n = y_{n-1} + h y_{n-1} = (1 + h) y_{n-1}
\end{cases}
$$

para $n = 1, 2, \ldots, N$.


Por inducción se obtiene la expresión explícita:
$$
y_n = (1 + h)^n = \left(1 + \frac{1}{N}\right)^n
$$

## Notación y clasificación de ecuaciones

### Notación de derivadas

Existen varias notaciones comunes para expresar derivadas en ecuaciones diferenciales:

**Notación de Lagrange**:
$$y', \quad y'', \quad y'''$$

**Notación de Newton**:
$$\dot{y}, \quad \ddot{y}, \quad \dddot{y}$$

**Notación de Leibniz**:
$$\frac{dy}{dt}, \quad \frac{d^2y}{dt^2}, \quad \frac{d^3y}{dt^3}$$

A lo largo del texto se utilizarán principalmente la notación de Lagrange y de Leibniz.

Además a lo largo del libro se usarán distintas letras para la variable independiente (t, x, s, etc.) y la función desconocida (y, u, v, etc.) dependiendo del contexto.

### Clasificación de ecuaciones diferenciales

::: {.panel-tabset}

#### Ecuaciones Ordinarias y en Derivadas Parciales

Las ecuaciones diferenciales se clasifican según el número de variables independientes:

**Ecuaciones Diferenciales Ordinarias (EDO)**
La función desconocida depende de una única variable independiente. Las derivadas son ordinarias.

$$y' = ky, \quad y'' + \omega^2 y = 0$$

**Ecuaciones en Derivadas Parciales (EDP)**
La función desconocida depende de dos o más variables independientes. Aparecen derivadas parciales.

$$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}, \quad \nabla^2 u = 0$$

#### Orden

::: {#def-orden}
####### Orden
El **orden** de una ecuación diferencial es el de la derivada de mayor orden que aparece en ella.
:::
$$
y^{(n)} = f(t, y, y', y'', \ldots, y^{(n-1)})
$$

La ecuación anterior es de orden $n$.

::: {#exm-orden .open}
- $y' = 3y^3$  es de **orden 1**
- $y'' + 2y' + y = 0$  es de **orden 2**
- $y''' - y' = \sin(t)$  es de **orden 3**
- $\frac{d^4y}{dt^4} + 2\frac{d^2y}{dt^2} = t^2$  es de **orden 4**
:::


#### Ecuaciones Lineales

::: {#def-ecuacion-lineal}
####### Ecuación lineal
Una ecuación diferencial ordinaria de orden $n$ es **lineal** si puede escribirse en la forma:

$$
a_n(t)y^{(n)} + a_{n-1}(t)y^{(n-1)} + \cdots + a_1(t)y' + a_0(t)y = g(t)
$$

donde $a_i(t)$ y $g(t)$ son funciones que dependen solo de $t$ (no de $y$ ni sus derivadas).
:::

**Características clave:**

- La variable dependiente $y$ y sus derivadas aparecen de forma lineal (no hay productos, potencias, ni composiciones)
- Si $g(t) = 0$, la ecuación es **homogénea**
- Si $g(t) \neq 0$, la ecuación es **no homogénea**

::: {#exm-lineal .open}
**Ecuaciones lineales:**

- $y' + 2y = e^t$ (lineal de orden 1, no homogénea)
- $y'' - 3y' + 2y = 0$ (lineal de orden 2, homogénea)
- $t^2y'' + ty' - y = \ln t$ (lineal de orden 2, no homogénea)

**Ecuaciones no lineales:**

- $y' = y^2$ 
- $y'' + (y')^2 + y = 0$ 
- $y'' + \sin(y) = 0$ 
:::

#### Ecuaciones Autónomas

Una ecuación diferencial ordinaria es **autónoma** si la variable independiente no aparece explícitamente en la ecuación.

**Forma general de una EDO autónoma de orden 1:**
$$y' = f(y)$$

**Forma general de una EDO autónoma de orden 2:**
$$y'' = f(y, y')$$

::: {#exm-autonoma .open}
**Ecuaciones autónomas:**

- $y' = ky$ 
- $y' = y(1 - y)$
- $y'' + \sin(y) = 0$

**Ecuaciones no autónomas:**

- $y' = t + y$ 
- $y'' + ty' + y = 0$
- $y' = e^t y$
:::

:::

### Forma estándar y forma normal

Una ecuación diferencial ordinaria de orden $n$ se puede expresar en **forma estándar** o **forma normal**:

::: {#def-forma-estandar}
####### Forma estándar

$$
F\left(t, y, y', y'', \ldots, y^{(n)}\right) = 0
$$
:::

La ecuación admite **forma normal** (o **forma explícita**) si es posible despejar la derivada de mayor orden:

::: {#def-forma-normal}
####### Forma Normal

$$
y^{(n)} = f\left(t, y, y', y'', \ldots, y^{(n-1)}\right)
$$
:::

::: {#exm-forma-normal}
La ecuación $y'' + 2y' + y = e^t$ en forma normal es:
$$
y'' = e^t - 2y' - y
$$

En forma estándar es:

$$
y'' - e^t + 2y' + y = 0
$$
:::

## Soluciones de ecuaciones

::: {#def-solucion-edo}
####### Solución

Una función $y: I \subset \mathbb{R} \to \mathbb{R}$ (o $y: I \to \mathbb{R}^m$) (derivable tantas veces como lo exija la ecuación) se dice **solución** de una EDO en el intervalo $I$ si, al sustituir $y(t)$ y sus derivadas en la ecuación, esta se verifica para todo $t \in I$.

En particular, si la EDO está en forma normal
$$
y^{(n)} = f\left(t, y, y', \ldots, y^{(n-1)}\right),
$$
entonces $y$ es solución si cumple
$$
y^{(n)}(t) = f\left(t, y(t), y'(t), \ldots, y^{(n-1)}(t)\right)\qquad \forall\, t\in I.
$$

:::

**Nota:** La definición de solución requiere que su dominio sea un intervalo $I$. Esto tiene dos implicaciones fundamentales:
1. **Conexión:** No se trabaja en conjuntos no conexos.

2. **Independencia de ramas:** Una solución puede generar múltiples soluciones si su dominio no es conexo. Cada intervalo conexo del dominio define una solución diferente.

Más adelante se entenderá el porque de limitar la definición de solución a un intervalo. Esta restricción asegura que la solución sea única y bien definida en ese intervalo.


### Soluciones explícitas e implícitas

Las soluciones se pueden expresar de forma explícita o implícita:

::: {#def-solucion-explicita}
####### Solución Explícita
Una solución es **explícita** si se puede escribir como una función de la variable independiente $y = \phi(t)$.
:::

::: {#def-solucion-implicita}
####### Solución Implícita
Una solución es **implícita** si se expresa mediante una relación $G(t, y) = 0$ que define a una o varias funciones $y=\phi(t)$ diferenciables en algún intervalo.
:::

::: {#exm-solucion-explicita-implicita}

La ecuación $y' = -\dfrac{x}{y}$ tiene como solución **implícita** la ecuación
$$
y^2 + x^2 =  C \quad C \in \mathbb{R}
$$

En forma **explícita**, la solución es 
$$
y = \pm \sqrt{C - x^2} \quad C \in \mathbb{R}
$$

**Nota:** se observa que la solución implícita no es una función, cada solución implícita puede definir varias soluciones explícitas.

### Comprobar que una función es solución

Para **comprobar que una función es solución** de una EDO, es suficiente con sustituirla en la ecuación y verificar que se cumple.

En los siguientes ejemplos se muestra soluciones de ecuaciones y su comprobación.

::: {.panel-tabset}

#### Una función varias soluciones

La ecuación $y' = \dfrac{1}{x^2}$ tiene como familia de soluciones $y = -\dfrac{1}{x} + C$ con $C \in \mathbb{R}$.

Para comprobar que es solución, se sustituye en la ecuación:

$$
\frac{d}{dx} \left( -\frac{1}{x} + C \right) = \frac{1}{x^2}
$$

Sin embargo esta función no está definida en $x=0$. Esto quiere decir que la expresión análitica genera **dos soluciones distintas**, una definida en $(-\infty, 0)$ y otra definida en $(0, \infty)$. Se denominan soluciones maximales y son objeto de estudio en cursos más avanzados. Además, son solución también en cualquier subintervalo de sus dominios. 

#### Implícita

::: {#exm-comprobar-implicita .open}

Dada la ecuación anterior $y' = -\dfrac{x}{y}$, se comprueba toda función diferenciable $y$ que sarisfaga la ecuación implícita $y^2 = -x^2 + C$ es solución.

Derivando ambos lados de la ecuación implícita respecto a $x$:

$$
y^2 = -x^2 + C
$$

$$
\frac{d}{dx}(y^2) = \frac{d}{dx}(-x^2 + C)
$$

$$
2y\frac{dy}{dx} = -2x
$$

$$
y' = -\frac{2x}{2y} = -\frac{x}{y}
$$

Por lo tanto, la solución implícita es solución de la ecuación.

:::

#### Explicita 

::: {#exm-comprobar-explicita .open}

Dada la ecuación anterior $y' = -\dfrac{x}{y}$, se comprueba que la función explícita $y = \pm \sqrt{-x^2 + C}$ es solución.

Sustituyendo directamente:

$$
\frac{d}{dx} \left( \pm \sqrt{-x^2 + C} \right) = -\frac{x}{\pm \sqrt{-x^2 + C}} = -\frac{x}{y}
$$

Por lo tanto, la solución explícita es solución de la ecuación. Además, es importante definir el **intervalo** en el que la función es solución, en este caso es solución en cualquier subintervalo de su dominio $x \in (-\sqrt{C}, \sqrt{C})$. Nótese que la función está definida en el intervalo cerrado $[-\sqrt{C}, \sqrt{C}]$ pero no es solución en los extremos porque no es diferenciable en esos puntos. Este es un buen ejemplo de como la función **puede ser solución en un intervalo pero no en su frontera.**

De esta reflexión surgirá la necesidad de una teoría que intente extender soluciones a su intervalo maximal de existencia, caracterizar cuando este existe y como se comporta la solución cerca de la frontera.
:::

#### Función a tramos

La ecuación diferencial puede estar definida por partes. Veamos como se comporta:

:::{#exm-comprobar-tramos .open}

Sea la EDO
$$
y' = \begin{cases} \cos x, & x \in (0, \pi), \\ 0, & x \notin (0, \pi). \end{cases}
$$

Se puede comprobar que $\sin x$ es solución en el intervalo $(0, \pi)$ pero no es solución en ningún intervalo que contenga puntos fuera de $(0, \pi)$. Habitualmente, se definen las soluciones a tramos intentando que sean continuas, por ejemplo:

$$
y(x) = \begin{cases} C_1, & x \leq 0, \\ \sin x + C, & x \in (0, \pi), \\ C_2, & x \geq \pi. \end{cases}
$$

Esta familia de soluciones define tres soluciones de la ecuación diferencial definidas respectivamente en $(-\infty, 0), (0, \pi), (\pi, \infty)$. Ya que la derivada en $\{0, \pi\}$ no está definida. Por ejemplo, el límite por la izquierda en $0$ es $0$ y por la derecha $\cos 0 = 1$. 

En función del modelo que represente nuestro problema, puede ser interesante definir la solución a tramos de forma que sea continua o incluso diferenciable. En este caso, se puede imponer solo la continuidad y se obtiene $C_1 = C$ y $C_2 = C + \sin \pi = C$. Por lo tanto, la familia de soluciones continuas es:
$$
y(x) = \begin{cases} C, & x \leq 0, \\ \sin x + C, & x \in (0, \pi), \\ C, & x \geq \pi. \end{cases}
$$

Por definición no son solución en los puntos $\{0, \pi\}$ pero la diferenciabilidad en esos puntos puede no ser necesaria a la hora de estudiar el fénomeno que se está modelizando. En análisis avanzado, este tipo de funciones que cumplen la ecuación en casi todo su dominio se conocen como soluciones en sentido **débil** o soluciones de **Carathéodory**.

::: {.content-visible when-format="html"}

## Problemas de valor inicial y de contorno

Se ha visto que una ecuación diferencial puede no tener una única solución, sino una **familia paramétrica** de funciones. Por ejemplo $y = Ce^{ax}$ para $y' = ay$. Sin embargo, un modelo describe **un** fenómeno concreto, así que una continuación natural es determinar cuál de todas esas soluciones es la que corresponde al fenómeno.

Para ello se imponen **condiciones adicionales** que seleccionen un subconjunto de la familia. Por ejemplo que pase por un punto, que tenga una pendiente dada o que tome valores prescritos en los extremos de un intervalo. La ecuación junto con estas condiciones forma un nuevo problema para el que se estudiará la existencia y unicidad de soluciones.

Según la forma de las condiciones se pueden caracterizar los problemas en diferentes tipos. En el curso se estudiarán principalmente los **problemas de valor inicial** y **los problemas de contorno**.

### Problemas de valor inicial

::: {#def-pvi}
####### Problema de valor inicial (PVI) o problema de Cauchy

Sean $I \subset \mathbb{R}$ un intervalo, $t_0 \in I$, $f$ una función dada y $y_0, \ldots, y_{n-1} \in \mathbb{R}$. Un **problema de valor inicial** de orden $n$ es el sistema
$$
\begin{cases}
y^{(n)}(t) = f\left(t, y(t), y'(t), \ldots, y^{(n-1)}(t)\right), & t \in I, \\[2pt]
y(t_0) = y_0,\ y'(t_0) = y_1,\ \ldots,\ y^{(n-1)}(t_0) = y_{n-1}.
\end{cases}
$$
:::

Un PVI puede tener una única solución, ninguna o varias:

::: {.panel-tabset}

#### Unicidad

Existe una única solución.

::: {#exm-pvi-unico .make-uncollapse}
####### PVI con solución única
Se considera el PVI
$$
\begin{cases}
y'' + y = 0, \\
y(0) = 0, \\
y'(0) = 1.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
Las soluciones de la ecuación, como se comprueba sustituyendo, son $y(x) = A\cos x + B\sin x$ con $A, B \in \mathbb{R}$. Las condiciones iniciales dan $y(0) = A = 0$ e $y'(0) = B = 1$, luego $y(x) = \sin x$. Hay **una única solución**, y además definida para todo $x \in \mathbb{R}$.
:::
:::

#### No existencia

No existe ninguna solución.

::: {#exm-pvi-sin-existencia .make-uncollapse}
####### Problema sin solución
Se considera
$$
\begin{cases}
x y' = 1, \\
y(0) = 0.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
Si $y$ fuera solución en un intervalo que contiene a $0$, al evaluar la ecuación en $x = 0$ se obtendría $0 \cdot y'(0) = 1$, es decir, $0 = 1$. Por tanto, **no hay solución**.

Fuera de $x = 0$ la ecuación equivale a $y' = 1/x$, cuyas soluciones $y = \ln|x| + C$ no están acotadas cerca de $0$.

Técnicamente, **no es un PVI** en el sentido de @def-pvi, porque la ecuación no admite forma normal en $x = 0$: no se puede despejar $y'$ como $f(x,y)$ con $f$ definida en ese punto.
:::
:::


#### Número finito

Existe un número finito de soluciones, mayor que uno.

::: {#exm-pvi-finitas .make-uncollapse}
####### Problema con exactamente dos soluciones
Se considera
$$
\begin{cases}
(y')^2 = 1, \\
y(0) = 0.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
Las funciones $y(x) = x$ e $y(x) = -x$ son soluciones. Además, no hay ninguna más: si $y$ es solución, $y'$ solo toma los valores $1$ y $-1$, y como una derivada tiene la propiedad del valor intermedio (teorema de Darboux), $y'$ es constante. Por tanto, hay **exactamente dos soluciones**. Tampoco se pueden empalmar tramos de ambas, porque la función resultante no sería derivable en el punto de empalme.

Técnicamente, **no es un PVI** en el sentido de @def-pvi, porque la ecuación no admite forma normal: al despejar se obtiene $y' = \pm 1$, que no es una única función $f(x,y)$. Un resultado interesante es que para una EDO en forma normal con $f$ continua, si hay más de una solución, hay infinitas.
:::
:::

#### Infinitas soluciones

Existen infinitas soluciones.

::: {#exm-pvi-infinitas .make-uncollapse}
####### PVI con infinitas soluciones
Se considera
$$
\begin{cases}
y' = \sqrt{y}, \\
y(0) = 0.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
La función $y = 0$ es solución. Si $y > 0$, separando variables, $\dfrac{\mathrm{d}y}{\sqrt{y}} = \mathrm{d}x$ da $2\sqrt{y} = x - c$, es decir, $y = \dfrac{(x-c)^2}{4}$ para $x > c$. Pegando ambas piezas, para cada $c \geq 0$ la función
$$
y_c(x) = \begin{cases} 0, & x \leq c, \\[2pt] \dfrac{(x-c)^2}{4}, & x > c, \end{cases}
$$
es derivable en todo $\mathbb{R}$ (en $x = c$ ambas derivadas valen $0$) y es solución del PVI. La solución puede **despegar del equilibrio** $y = 0$ en cualquier instante $c \geq 0$, de modo que hay **infinitas soluciones**.

::: {.content-visible when-format="html"}

Estos problemas son de interés fundamental porque bajo ciertas hipótesis permiten determinar una solución única. Si las condiciones se imponen en los extremos de un intervalo, se trata de un **problema de contorno** o **problema de valores en la frontera**.

### Problemas de contorno

::: {#def-problema-frontera}
####### Problema de valores en la frontera

Sean $a < b$, $f$ una función dada y $g_1, \ldots, g_n$ funciones dadas. Un **problema de valores en la frontera** (o de contorno) de orden $n \geq 2$ es el sistema
$$
\begin{cases}
y^{(n)}(x) = f\left(x, y(x), y'(x), \ldots, y^{(n-1)}(x)\right), & x \in (a,b), \\[2pt]
g_i\left(y(a), \ldots, y^{(n-1)}(a),\, y(b), \ldots, y^{(n-1)}(b)\right) = 0, & i = 1, \ldots, n.
\end{cases}
$$

:::


#### Tipos de condiciones de contorno

Se vuelve a considerar la ecuación $y'' + y = 0$, de solución general $y(x) = A\cos x + B\sin x$. La ecuación es siempre la misma, sin embargo, según las condiciones, se obtiene **una**, **infinitas** o **ninguna** solución. 

::: {.panel-tabset}

##### Dirichlet

Se fija el **valor** de la solución en los extremos: $y(a) = \alpha$, $y(b) = \beta$.

::: {#exm-condiciones-dirichlet .make-uncollapse}
####### Condiciones de Dirichlet
Sobre $[0, \pi]$, se estudian las soluciones, según el valor de $\beta$, de
$$
\begin{cases}
y'' + y = 0, & x \in (0,\pi), \\
y(0) = 0, \\
y(\pi) = \beta.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
Con $y = A\cos x + B\sin x$, la primera condición da $A = 0$ y la segunda $y(\pi) = -A = \beta$:

- Si $\beta = 0$: $B$ queda libre, luego $y(x) = B\sin x$. **Infinitas soluciones.**
- Si $\beta \neq 0$ (por ejemplo $\beta = 1$): se exige $-A = \beta$ pero $A = 0$. **No hay solución.**

Sin embargo, el problema
$$
\begin{cases}
y'' + y = 0, & x \in (0,\pi/2), \\
y(0) = 0, \\
y(\pi/2) = 1,
\end{cases}
$$
da $A = 0$, $B = 1$ y la **solución única** $y(x) = \sin x$.
:::
:::

##### Neumann

Se fija el valor de la **derivada** en los extremos: $y'(a) = \alpha$, $y'(b) = \beta$. Físicamente suele representar un flujo (de calor, de materia...) en el borde.

::: {#exm-condiciones-neumann .make-uncollapse}
####### Condiciones de Neumann
Sobre $[0, \pi]$, se considera
$$
\begin{cases}
y'' + y = 0, & x \in (0,\pi), \\
y'(0) = 0, \\
y'(\pi) = 0.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
Como $y'(x) = -A\sin x + B\cos x$, la primera condición da $B = 0$ y la segunda se cumple siempre. Quedan **infinitas soluciones** $y(x) = A\cos x$.
:::
:::

##### Robin

Se fija una **combinación** del valor y de la derivada: $y'(a) + \gamma\, y(a) = \alpha$, con $\gamma \in \mathbb{R}$. Contiene a Dirichlet y a Neumann como casos particulares, y también se pueden imponer condiciones de tipos distintos en cada extremo.

::: {#exm-condiciones-robin .make-uncollapse}
####### Condición de Robin
Sobre $[0, \pi]$, se considera
$$
\begin{cases}
y'' + y = 0, & x \in (0,\pi), \\
y(0) = 0, \\
y'(\pi) + y(\pi) = 1.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
De $y(0)=0$ se tiene $y = B\sin x$, y entonces $y'(\pi) + y(\pi) = -B = 1$. La **solución única** es $y(x) = -\sin x$.
:::
:::

##### Otras

Existen muchas más posibilidades. Por ejemplo, las condiciones **periódicas** $y(a) = y(b)$, $y'(a) = y'(b)$ también encajan en la definición de problema de frontera. Las condiciones en puntos interiores del intervalo no encajan en ella y no se estudian.

:::

Los ejemplos anteriores ilustran distintos tipos de condiciones en los problemas de frontera y cómo restricciones diferentes sobre la solución afectan a la existencia y unicidad de soluciones.

Las pregunta relacionadas con las caracteristicas de las soluciones, como su existencia, unicidad, estabilidad y comportamiento a largo plazo, son el objeto de estudio del **análisis cualitativo** de las ecuaciones diferenciales. En la siguiente sección se tratarán ejemplos y técnicas para abordar estos aspectos.

## Análisis cualitativo

Cualquier caracteristica de las soluciones de una ecuación diferencial deducida sin conocer la solución explícita es objeto de estudio del análisis cualitativo. Es un campo amplio y con distintos enfoques, por ejemplo la existencia y unicidad de soluciones, comportamiento asintótico y la existencia de soluciones periódicas o casi periódicas.

### Existencia y Unicidad de soluciones 

El desarrollo de la teoría completa requiere herramientas de análisis que no se abordarán, pero se presentarán los resultados esenciales y sus implicaciones.

#### Existencia: teorema de Peano

El teorema de Peano establece que la continuidad de $f$ es **condición suficiente** para la **existencia local** de solución. 

::: {#thm-peano}
####### Teorema de existencia de Peano

Sean $\Omega \subset \mathbb{R} \times \mathbb{R}^n$ abierto y $f \colon \Omega \to \mathbb{R}^n$ continua. Entonces, para cada $(t_0, y_0) \in \Omega$ existe $\delta > 0$ tal que el PVI
$$
\begin{cases}
y' = f(t,y), \\
y(t_0) = y_0,
\end{cases}
$$
tiene **al menos una solución** definida en $[t_0 - \delta, t_0 + \delta]$.
:::

::: {.remark data-title="Peano y los ejemplos anteriores"}
El PVI de @exm-pvi-infinitas tiene $f$ continua, así que el teorema de Peano asegura su existencia, pero no su unicidad: la continuidad no basta para ella. En cambio, el PVI de @exm-pvi-sin-existencia no contradice el teorema: su ecuación no admite forma normal en $x = 0$ y, al despejar, $f(x,y) = 1/x$ no es continua allí.
:::

#### Unicidad: teorema de Picard-Lindelöf

Para garantizar la **unicidad** de la solución, se requiere una condición adicional sobre la función $f$. A continuación se introducen conocimientos sobre este resultado con el objetivo de desarrollar una intuición y de picar la curiosidad del lector sobre una continuidad natural de esta asignatura.

##### Funciones lipschitzianas

La condición para unicidad será la lipschitzianid de $f$. Aunque la equivalencia más comoda en terminos practicos es la regularidad respecto de la variable dependiente $y$, que limita la rapidez con la que $f(t,y)$ puede variar al cambiar $y$.

En lo que sigue, $\|\cdot\|$ denota una norma fija de $\mathbb{R}^n$.

::: {#def-lipschitz-global}
####### Función globalmente lipschitziana

Sean $I \subset \mathbb{R}$ un intervalo, $E \subset \mathbb{R}^n$ y $f \colon I \times E \to \mathbb{R}^n$. Se dice que $f$ es **globalmente lipschitziana en $y$** (uniformemente en $t$) en $I \times E$ si existe $L \geq 0$ tal que
$$
\|f(t,y_1) - f(t,y_2)\| \leq L\,\|y_1 - y_2\| \qquad \text{para todo } t \in I,\ y_1, y_2 \in E.
$$
$L$ es la **constante de Lipschitz** de la función.
:::

También se puede definir la Lipschitzianidad de manera local, considerando entornos alrededor de cada punto.

::: {#def-lipschitz-local}
####### Función localmente lipschitziana

Sean $\Omega \subset \mathbb{R} \times \mathbb{R}^n$ abierto y $f \colon \Omega \to \mathbb{R}^n$. Se dice que $f$ es **localmente lipschitziana en $y$** si cada punto $(t_0, y_0) \in \Omega$ tiene un entorno $[t_0-a, t_0+a] \times \overline{B}(y_0, r) \subset \Omega$ en el que $f$ es globalmente lipschitziana en $y$ (@def-lipschitz-global). La constante $L$ puede depender del entorno.
:::

La definición de Lipschitz puede ser difícil de verificar directamente. Cuando $f$ es derivable respecto de $y$, la condición de Lipschitz equivale a que esa derivada esté acotada.

::: {#prp-lipschitz-derivada}
####### Condición de Lipschitz y derivadas acotadas

Sean $I \subset \mathbb{R}$ un intervalo, $E \subset \mathbb{R}^n$ abierto y convexo, y $f \colon I \times E \to \mathbb{R}^n$ continua con derivada parcial $\dfrac{\partial f}{\partial y}$ (matriz jacobiana respecto de $y$) continua en $I \times E$. Dado $L \geq 0$, son equivalentes:

1. $f$ es globalmente lipschitziana en $y$ con constante $L$.
2. $\left\| \dfrac{\partial f}{\partial y}(t,y) \right\| \leq L$ para todo $(t,y) \in I \times E$.

:::

El criterio más aplicable en la practica para verificar la Lipschitzianidad se limita a comprobar si la derivada parcial respecto de $y$ está acotada para garantizar lipschitzianidad local.

::: {#cor-lipschitz-local}
####### Criterio de lipschitzianidad local

Sea $\Omega \subset \mathbb{R} \times \mathbb{R}^n$ abierto y $f \colon \Omega \to \mathbb{R}^n$ continua con $\dfrac{\partial f}{\partial y}$ continua en $\Omega$. Entonces $f$ es localmente lipschitziana en $y$.
:::



::: {#exm-lipschitz .make-uncollapse}
####### Funciones lipschitzianas y no lipschitzianas
Se estudia si las siguientes funciones son lipschitzianas en $y$:

(a) $f(t,y) = \sin y$ en $\mathbb{R} \times \mathbb{R}$;

(b) $f(t,y) = y^2$ en $\mathbb{R} \times \mathbb{R}$;

(c) $f(t,y) = \sqrt{|y|}$ en $\mathbb{R} \times \mathbb{R}$.

::: {.solution .make-collapse data-title="Solución"}
(a) $\left|\dfrac{\partial f}{\partial y}\right| = |\cos y| \leq 1$ en $\mathbb{R}$. Por la @prp-lipschitz-derivada, $f$ es **globalmente lipschitziana** con $L = 1$.

(b) $\dfrac{\partial f}{\partial y} = 2y$ no está acotada en $\mathbb{R}$. De hecho, $|f(t,y_1) - f(t,y_2)| = |y_1+y_2|\,|y_1-y_2|$ y el factor $|y_1+y_2|$ no está acotado, luego $f$ **no es globalmente lipschitziana**. En cada intervalo $[-R,R]$ la derivada está acotada por $2R$, así que sí es **localmente lipschitziana** (@cor-lipschitz-local).

(c) $\dfrac{|f(t,y) - f(t,0)|}{|y|} = |y|^{-1/2} \to \infty$ cuando $y \to 0$, luego $f$ **no es lipschitziana en ningún entorno de** $y = 0$. Equivalentemente, $\dfrac{\partial f}{\partial y} = \dfrac{\operatorname{sgn} y}{2\sqrt{|y|}}$ no está acotada cerca de $0$. Esto es lo que ocurre en @exm-pvi-infinitas, donde falla la unicidad.
:::
:::

#### Teorema de Picard–Lindelöf

Si se exige a $f$ continuidad y la condición de Lipschitz respecto de $y$, se obtiene unicidad. Hay dos versiones, según se imponga la condición en todo el espacio o solo localmente.

::: {#thm-picard-lindelof-global}
####### Teorema de Picard–Lindelöf (versión global)

Sean $I = [a,b]$ y $f \colon I \times \mathbb{R}^n \to \mathbb{R}^n$ continua y globalmente lipschitziana en $y$, uniformemente en $t$. Entonces, para cualesquiera $t_0 \in I$ e $y_0 \in \mathbb{R}^n$, el PVI
$$
\begin{cases}
y' = f(t,y), \\
y(t_0) = y_0,
\end{cases}
$$
tiene una **única solución** definida en todo el intervalo $I$.
:::
La versión local solo garantiza existencia y unicidad en un entorno del punto inicial.


::: {#thm-picard-lindelof-local}
####### Teorema de Picard–Lindelöf (versión local)

Sean $\Omega \subset \mathbb{R} \times \mathbb{R}^n$ abierto y $f \colon \Omega \to \mathbb{R}^n$ continua y localmente lipschitziana en $y$. Entonces, para cada $(t_0, y_0) \in \Omega$ existe $\delta > 0$ tal que el PVI
$$
\begin{cases}
y' = f(t,y), \\
y(t_0) = y_0,
\end{cases}
$$
tiene una **única solución** definida en $[t_0 - \delta, t_0 + \delta]$.
:::


La demostración se basa en que $y$ es solución del PVI si y solo si es continua y cumple la ecuación integral
$$
y(t) = y_0 + \int_{t_0}^{t} f(s, y(s))\,\mathrm{d}s.
$$
Si $f$ es lipschitziana en $y$, la aplicación que a una función $y$ le asigna el segundo miembro es una contracción y el teorema del punto fijo de Banach da existencia y unicidad.


::: {.remark data-title="Alcance de la condición de Lipschitz"}
La condición de Lipschitz es **suficiente pero no necesaria** para la unicidad. Además, en la versión local $\delta$ depende del punto $(t_0, y_0)$, y no se puede sustituir por un intervalo fijo, como muestra el siguiente ejemplo.
:::

::: {#exm-pvi-explosion .make-uncollapse}
####### Existencia solo local
Se considera
$$
\begin{cases}
y' = y^2, \\
y(0) = 1.
\end{cases}
$$

::: {.solution .make-collapse data-title="Solución"}
La función $f(t,y) = y^2$ es de clase $C^1$, luego localmente lipschitziana (@cor-lipschitz-local). Por el @thm-picard-lindelof-local hay una única solución local. Separando variables se obtiene
$$
y(t) = \frac{1}{1-t}, \qquad t < 1,
$$
que **explota en tiempo finito**: $y \to \infty$ cuando $t \to 1^-$. La solución solo existe en $(-\infty, 1)$ aunque $f$ sea regular en todo $\mathbb{R}$, y no es globalmente lipschitziana (@exm-lipschitz), así que no se puede aplicar la versión global.
:::
:::

En resumen, para $y' = f(t,y)$ con $y(t_0) = y_0$:

| Hipótesis sobre $f$                         | Conclusión                                                 |
| :------------------------------------------ | :--------------------------------------------------------- |
| Continua                                    | Existencia local (Peano)                                   |
| Continua y localmente lipschitziana en $y$  | Existencia y unicidad locales (Picard–Lindelöf local)      |
| Continua y globalmente lipschitziana en $y$ | Existencia y unicidad en todo $I$ (Picard–Lindelöf global) |

### Comportamiento de las soluciones

Una práctica frecuente, consiste en deducir propiedades de las soluciones
a partir de las profiedades de la ecuación diferencial.

Se procederá a definir un campo vectorial asociado a la ecuación diferencial, un conjunto de curvas (isoclinas) que lo describen y técnicas para deducir el comportamiento de las soluciones como monotonía, límite y estabilidad.

#### Campo de direcciones e isoclinas

Dada una ecuación diferencial de la forma $y' = f(x,y)$, se puede asociar un campo de direcciones que describe la pendiente de las soluciones en cada punto del plano $(x,y)$. Este campo permite visualizar cómo se comportan las soluciones ya que localmente las soluciones son tangentes al campo en cada punto.

::: {#def-campo-direcciones}
####### Campo de direcciones

Sean $\Omega \subset \mathbb{R}^2$ y $f \colon \Omega \to \mathbb{R}$. El **campo de direcciones** de la ecuación $y' = f(x,y)$ es el campo vectorial
$$
\Omega \to \mathbb{R}^2, \qquad (x,y) \longmapsto \big(1,\ f(x,y)\big),
$$
que asigna a cada punto $(x,y)$ la dirección de pendiente $f(x,y)$.
:::

::: {.remark data-title="Elección del vector"}
La pendiente de un vector $(v_1, v_2)$ es $v_2 / v_1$. Para que el campo tenga pendiente $f(x,y)$ en el punto $(x,y)$ basta con elegir un vector con $v_2 / v_1 = f(x,y)$. La opción más sencilla es $v_1 = 1$, que da el vector $\big(1,\ f(x,y)\big)$. Normalmente se normaliza el campo para que tenga longitud unitaria.
$$
\frac{(1, f(x,y))}{\sqrt{1 + f(x,y)^2}}
$$
:::

Dibujar el campo de direcciones consiste en representar en cada punto de una malla un vector que indique la dirección de la pendiente. Para facilitar el trabajo se encuentran las curvas donde la pendiente es constante. De esta manera se pueden dibujar el campo de manera más rápida.

::: {#def-isoclina}
####### Isoclina

Sea $m \in \mathbb{R}$. La **isoclina** de pendiente $m$ de la ecuación $y' = f(x,y)$ es el conjunto de soluciones de la ecuación
$$
\{(x,y) \in \Omega : f(x,y) = m\}.
$$
:::

###### $y' = -x/y$

Las isoclinas son perpendiculares al campo.

::: {#exm-campo-circunferencias .make-uncollapse}
####### Campo de y' = -x/y
Se considera la ecuación
$$
y' = -\frac{x}{y}, \qquad y \neq 0.
$$

- Definir el campo de direcciones
- Definir las isoclinas
- Dibujar el campo y analizar el comportamiento de las soluciones

::: {.solution .make-collapse data-title="Solución"}
**Campo de direcciones.** Por @def-campo-direcciones, el campo es $\left(1, -\dfrac{x}{y}\right)$.

**Isoclinas.** La ecuación $-\dfrac{x}{y} = m$ equivale a
$$
y = -\frac{x}{m} \quad \text{si } m \neq 0, \qquad x = 0 \quad \text{si } m = 0.
$$
Son **rectas vectoriales** (por el origen, que se excluye) de pendiente $-1/m$. El producto de esta pendiente por la del campo, $m$, es $-1$, luego **cada isoclina es perpendicular al campo en sus puntos**. Para $m = 0$ la isoclina es el eje $y$ y el campo es horizontal.

**Comportamiento de las soluciones.** El campo es ortogonal en cada punto a las isoclinas, que son rectas radiales. Por lo tanto, las soluciones son son las de las circunferencias centradas en el origen. 
:::

::: {.solution .make-collapse data-title="Campo de direcciones"}

###### $y' = x/y$

La pendiente de la isoclina es la inversa de la del campo.

::: {#exm-campo-hiperbolas-cuadrados .make-uncollapse}
####### Campo de y' = x/y
Se considera la ecuación
$$
y' = \frac{x}{y}, \qquad y \neq 0.
$$

- Definir el campo de direcciones
- Definir las isoclinas
- Dibujar el campo y analizar el comportamiento de las soluciones

::: {.solution .make-collapse data-title="Solución"}
**Campo de direcciones.** Por @def-campo-direcciones, el campo es $\left(1, \dfrac{x}{y}\right)$.

**Isoclinas.** La ecuación $\dfrac{x}{y} = m$ equivale a
$$
y = \frac{x}{m} \quad \text{si } m \neq 0, \qquad x = 0 \quad \text{si } m = 0.
$$
Son **rectas vectoriales** (por el origen, que se excluye) de pendiente $1/m$, la inversa de la del campo en sus puntos. Para $m = \pm 1$ ambas pendientes coinciden, así que las rectas $y = \pm x$ son isoclinas y a la vez soluciones. Para $m = 0$ la isoclina es el eje $y$ y el campo es horizontal.

**Comportamiento de las soluciones.** Las rectas $y = x$ e $y = -x$ son las únicas isoclinas tangentes al campo ($m = \pm 1$), luego también son soluciones, y ninguna otra solución las puede cruzar. En el cuadrante $x>0,\,y>0$ el signo de $y' = x/y > 0$ hace que las soluciones sean crecientes; al no poder cruzar la recta $y = x$ y ser monótonas, se aproximan a ella asintóticamente cuando $x \to \infty$, por encima o por debajo según el punto de partida. Por simetría ($f(-x,-y) = f(x,y)$ y $f(x,-y) = -f(x,y)$), el mismo argumento da en los demás cuadrantes ramas asintóticas a $y = x$ o a $y = -x$: las soluciones son ramas de hipérbola con esas dos rectas como asíntotas.
:::

::: {.solution .make-collapse data-title="Campo de direcciones"}

###### $y' = y/x$

Las isoclinas son tangentes al campo.

::: {#exm-campo-rectas .make-uncollapse}
####### Campo de y' = y/x
Se considera la ecuación
$$
y' = \frac{y}{x}, \qquad x \neq 0.
$$

- Definir el campo de direcciones
- Definir las isoclinas
- Dibujar el campo y analizar el comportamiento de las soluciones

::: {.solution .make-collapse data-title="Solución"}
**Campo de direcciones.** Por @def-campo-direcciones, el campo es $\left(1, \dfrac{y}{x}\right)$.

**Isoclinas.** La ecuación $\dfrac{y}{x} = m$ equivale a
$$
y = mx, \qquad m \in \mathbb{R}.
$$
Son **rectas vectoriales** (por el origen, que se excluye) de pendiente $m$, igual a la del campo en sus puntos, luego **cada isoclina es tangente al campo**.

**Comportamiento de las soluciones.** Al ser el campo tangente a cada isoclina, toda isoclina es solución: las soluciones son exactamente las semirrectas abiertas $y = kx$ con $x > 0$ o con $x < 0$ (el origen queda excluido, pues $x \neq 0$). Es una situación poco habitual, consecuencia de que $f$ depende solo de $y/x$.
:::

###### $y' = -y/x$

La pendiente de la isoclina es la opuesta a la del campo.

::: {#exm-campo-hiperbolas-producto .make-uncollapse}
####### Campo de y' = -y/x
Se considera la ecuación
$$
y' = -\frac{y}{x}, \qquad x \neq 0.
$$

- Definir el campo de direcciones
- Definir las isoclinas
- Dibujar el campo y analizar el comportamiento de las soluciones

::: {.solution .make-collapse data-title="Solución"}
**Campo de direcciones.** Por @def-campo-direcciones, el campo es $\left(1, -\dfrac{y}{x}\right)$.

**Isoclinas.** La ecuación $-\dfrac{y}{x} = m$ equivale a
$$
y = -mx, \qquad m \in \mathbb{R}.
$$
Son **rectas vectoriales** (por el origen, que se excluye) de pendiente $-m$, la opuesta a la del campo en sus puntos. Solo para $m = 0$ coinciden: el eje $x$ es isoclina y solución.

**Comportamiento de las soluciones.** El eje $x$ ($m = 0$) es la única isoclina tangente al campo, y la única que es también solución. El signo de $y' = -y/x$ hace que las soluciones decrezcan en los cuadrantes I y III y crezcan en el II y IV. El campo es ortogonal en cada punto al de $y' = x/y$ (@exm-campo-hiperbolas-cuadrados), así que las soluciones son las trayectorias ortogonales de sus ramas de hipérbola: ramas de hipérbola con los ejes coordenados como asíntotas.

curvas_parametrico = {
  const niveles = [1, 2, 4, 9];
  const L = 3;
  const n = 150;
  const ramas = [];
  for (const C of [...niveles, ...niveles.map(c => -c)]) {
    const puntos = [];
    for (let i = 0; i <= n; i++) {
      const x = -L + 2 * L * i / n;
      const expr = C + a_parametrico * x * x;
      if (expr < 0) continue;
      puntos.push({x, y: Math.sqrt(expr)});
    }
    if (puntos.length > 1) {
      ramas.push(puntos);
      ramas.push(puntos.map(p => ({x: p.x, y: -p.y})));
    }
  }
  return ramas;
}

dibujarCampo({
  f: (x, y) => a_parametrico * x / y,
  direccionIsoclina: (m) => [m, a_parametrico],
  curvas: curvas_parametrico,
  opciones: opc_parametrico
})

## Modelos

Los modelos matemáticos que estudiaremos cumplen tres propiedades fundamentales:

- **Determinismo**: el estado futuro y pasado del sistema está completamente determinado por su estado inicial. No existe ambigüedad: las soluciones determinadas por las condiciones iniciales son únicas.
- **Diferenciabilidad**: las funciones que describen la evolución del sistema son continuas y derivables. Esta hipótesis, nos permitirá garantizar la existencia de soluciones.
- **Finito-dimensionalidad**: el sistema se describe mediante un número finito de variables. Cada estado del sistema puede representarse como un punto en un espacio euclídeo de dimensión $n$.

En conjunto, estas tres propiedades definen el marco clásico de las **ecuaciones diferenciales ordinarias**, que constituyen la base teórica de buena parte de la modelización matemática en ciencias e ingeniería.
